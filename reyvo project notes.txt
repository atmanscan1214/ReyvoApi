Start the API
On Windows, use the Selector-loop factory (psycopg can't use the default Proactor loop):

cd D:\Projects\Reyvo\src
uv run uvicorn reyvo.main:app --reload --port 8000 --loop reyvo.dev:selector_loop_factory
Then either:

Open http://localhost:8000/docs, call POST /api/v1/auth/login, and paste the returned access_token into Scalar's Authorize button, or
Use PowerShell:
$login = Invoke-RestMethod -Method Post `
  -Uri http://localhost:8000/api/v1/auth/login `
  -ContentType "application/json" `
  -Body (@{ email = "demo@reyvo.com"; password = "ReyvoDemo123!" } | ConvertTo-Json)

$login.access_token
